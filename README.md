# Soil Quality Index (SQI) Analysis-Cox's Bazar

An advanced Excel-based environmental data science project evaluating soil nutrient profiles and physio-chemical indicators across multiple sampling locations. This project processes primary soil parameters to calculate individual indicator scores, compute overall Soil Quality Index (SQI) values, and classify soil health tiers.

## 📊 Project Overview

This study assesses soil parameters across 15 sampling locations (such as Kolatoli, Himchari, Inani, Naf River Bank, and Shah Porir Island) by analyzing key nutrient and physio-chemical indicators—including Nitrogen (N), Phosphorus (P), Potassium (K), pH, Temperature, Electrical Conductivity (EC), and Humidity.

## 📁 Repository Contents

* **`Soil_Quality_Index_Analysis.xlsx`**: Primary Excel workbook featuring:
  * **Main Data Sheet**: Raw dataset with indicator scores (N, P, K, pH, Temp, EC, Humidity), calculated final SQI values, and assigned Soil Quality Classes (*Good, Moderate, Poor*).
  * **Pivot Table Sheet**: Statistical aggregations evaluating average SQI and parameter scores across locations and quality classes.
  * **Dashboard Sheet**: Dynamic visualization suite featuring dynamic charts and interactive slicers.
* **`Soil_Quality_Index_Dashboard.png`**: High-resolution screenshot preview of the final Excel dashboard.

## 🛠️ Excel Techniques & Analytical Features Used

* **Multi-Parameter Scoring & Modeling**: Automated transformation of soil nutrient and physical parameters into normalized score metrics.
* **SQI Aggregation & Health Classification**: Computed overall Soil Quality Index to categorize samples into health classes (*7% Good, 20% Moderate, 73% Poor*).
* **PivotTable Summaries**: Grouped evaluations comparing nutrient scores against physical indicators per location.
* **Interactive Dashboard Design**:
  * **Horizontal Bar Charts**: Location-wise SQI comparisons and parameter breakdown scores.
  * **Donut Chart**: Visual distribution (%) of overall Soil Quality Classes.
  * **Interactive Slicers**: Dynamic filtering by *Local Name* and *Soil Quality Class*.

## 🚀 Getting Started

1. Download or clone this repository to your local machine.
2. Open **`Soil_Quality_Index_Analysis.xlsx`** in Microsoft Excel.
3. Explore the worksheets to review parameter scores, PivotTable aggregations, and test interactive dashboard slicers.
